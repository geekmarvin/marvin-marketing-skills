# 资料与证据规则

默认以当前 Brief、用户提供的文件和可核验的公开出处开展工作。需要事实而缺少可访问出处时，保留假设、条件或验证动作。引用按来源类型写文件名与章节、页码或网址；内部资产 ID 仅在实际使用该资产时附上。

根据用途区分材料。只准启发的材料只能帮助构思；参考材料的判断标为待复核；证据材料仍要验证原始出处、时间、口径、可引用范围和适用条件。明确限制使用的资料予以排除。把项目输入、观察结果与目标、预测、提案承诺和拟定试验阈值分别标注。

如用户明确授权并指明私有知识库入口，在可读范围内查项目指定的当前索引或知识地图，按任务筛选。保留访问范围、引用权限、原始位置和必要的资产 ID。缺入口、索引或原件时回到当前工作材料，未核实的主张保留待验证。
