# 付费预算追加前的能力核验

用于以到页、交易或留资数据决定是否追加平台预算的试点。记录拟用平台、账户、能力、证据与日期、核验人、当前状态及失败处理。现有账号、可生成链接、后台显示功能名称都可以是输入。能力是否适用于本试点，以拟用账户和实际设置的核验为准。

| 能力 | 如何核验 | 未通过时的决定 |
|---|---|---|
| 投放资格与花费控制 | 复核当前平台规则和账户权限，确认能设置预算上限，并能分别暂停对应投放。 | 初始付费和追加均暂缓。 |
| 素材、链接和承接 | 从拟用广告入口预览或用获准的试验流量，分别走到正确商品页或表单，验证各组落地与标记。 | 暂缓出现问题的付费入口和预算追加，修复后复测。 |
| 区分付费与自然流量，并能导出对应花费 | 验证付费来源标记能保留到可对账的数据，且花费、访问与转化可按计划所需的层级匹配。 | 暂停基于付费转化或获客成本的追加。 |
| 转化归因与重复处理 | 用测试点击、订单或留资核对事件记录。明确归因窗、同一订单或线索跨组的唯一归属，以及计算所需的退款、取消或无效线索字段可导出。 | 核验未完成或来源无法归属时，暂停依赖这些指标的追加。退款等未成熟的数据可用于排查，等到约定观察窗后再依据净结果决定扩量。 |
| 同期互斥分流（正式对照试验适用） | 在拟用账户验证两组同期、互斥、关键设置可比，并记录实际分配。 | 暂停正式对照的追加。上述基础能力都通过时，可让业务方另行确认小额探索方案，记录差异和限制，按探索信号解读。 |

初始小额核验及后续追加分别写明上限与条件。在能力核验通过之后，再评估本项目拟定的样本、经济性和资源条件，决定是否释放对应预算。
