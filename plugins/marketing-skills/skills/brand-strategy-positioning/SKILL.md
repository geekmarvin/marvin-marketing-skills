# 品牌策略与定位

1. 整理产品事实、目标用户、竞品参照、业务取舍和可用证据。把创始人偏好纳入表达约束，用户动机由用户证据支持。
2. 给出至少两条真正不同的定位路径，每条写清优先人群、场景、核心承诺、支持理由、舍弃什么、最大风险和验证方式。推荐一条路径并说明触发改判的条件。
3. 仅凭产品事实或零散线索时交付探索版，列假设和命名方向。证据充分时交付决策版，补齐价值表达、关键触点原则及一致性检查。
4. 需要锁定正式定位、名称或对外承诺时，请业务方确认具体路径。命名候选附待核验事项，按[证据规则](../_shared/evidence.md)核查支撑性主张。

交付路径对照、首选及理由、分触点表达原则和验证计划。
