# 电商与直播转化增长

1. 确认商品、价格与权益、库存或承接资源、转化事件和时间窗。用真实漏斗数据定位断点；数据不足时把断点写为假设，给出所需计数、口径与来源。
2. 串起兴趣、互动、留资和转化。只在业务有后续销售跟进时设留资。每段写明承接机制、可观测信号、责任方和用户下一步。说明先解决哪一段和其余环节如何作为观察信号。
3. 设计一个可执行试验，每次优先改变一个关键变量。写出分流或对照、预算、样本及观察窗口、分母、归因及退款去重口径。把继续、调整、停止条件与单位经济、库存或跟进能力相连。按[能力核验](../_shared/paid-readiness.md)先判断追加资格，再评估指标。互斥分流缺失时，单列可获批准的探索路径及其限制。
4. 将用户给出的数据、计算、试验阈值和将来观测结果分别记录。分不清来源或试验量不足时按探索性结果解读。对外的效益、规则和数据按[证据规则](../_shared/evidence.md)复核。

交付漏斗表、试验设置、判定规则和负责人。与内容环节对齐渠道入口、追踪和承接页。
