# 出海本地化策略

1. 界定目标国家、细分客户、SKU、供货及履约范围。按产品适配、服务体验、信任与认证、合规、供应链和退货成本审查进入约束。
2. 为候选市场写出机会、进入假设、可替代路径与当前证据。优先核验当地监管机构、官方统计和业务方资料的适用条件。没有可核验数据时交付候选或待确认区间。
3. 把推荐写成可控试点，明确试点范围、期限、本地验证责任人、指标和暂停阈值。以退款、履约或单位经济判断扩量条件；合规结论保留专业核验环节。
4. 在承诺市场、SKU、履约和扩量前，请用户确认具体方案。证据强度及适用时间按[证据规则](../_shared/evidence.md)记录。

交付市场与约束对照表、试点建议和当地验证清单。
