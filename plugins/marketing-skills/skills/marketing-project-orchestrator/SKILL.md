# 营销项目编排

1. 确认用户需要的交付物、决策、已有输入、事实风险和时限。从[路由与交接](references/routing.md)选最短路径。只有某阶段的输出会改变下一阶段的决策时才加入该阶段。
2. 用同包专业 Skill 完成必要步骤。每个交接仅传递已确认事实、必要的决策和约束、明确假设及待验证项。找不到专业 Skill 时，说明缺失环节，用现有输入完成可交付的部分。
3. 面向外部或包含关键事实、数据及效果主张时，交 08 逐条审查。内部探索则根据风险选择即时审查或留下证据缺口，按[证据规则](../_shared/evidence.md)处理引用。
4. 汇总为一份交付，明确采用的路径、阶段产物、用户需决定的事项与仍待验证的主张。

普通项目使用当前工作材料。需要扩展到用户明确授权的资料时，按证据规则定位到指定入口。
