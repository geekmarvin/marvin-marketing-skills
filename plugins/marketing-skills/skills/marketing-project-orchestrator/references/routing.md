# 营销任务路由与交接

下表中的路径可按用户已有输入缩短。输出将用于对外沟通或含高影响事实时安排 08。

| 任务 | 启动路径 | 关键交接 |
|---|---|---|
| 模糊需求或增长问题 | 01，按待决策项进入 02、03、05 或 06 | 决策、行为链路、证据缺口 |
| 市场与消费者洞察 | 02，必要时先用 01 确认决策 | 人群、需求情境、证据强度、验证任务 |
| 品牌定位或焕新 | 03，洞察缺失时补 02 | 人群、核心承诺、支持理由、表达约束 |
| 新品整合传播 | 04 → 05，需要交易或留资时接 06 | 核心行为、创意机制、内容承接、漏斗 |
| 内容或平台方案 | 05，需要交易承接时接 06 | 内容支柱、渠道分工、下一跳、衡量 |
| 店播、内容电商或留资增长 | 06，有内容缺口时接 05 | 断点、试验、指标、负责人、停损 |
| 出海市场进入 | 07，市场问题需补资料时接 02 | 项目范围、当地证据、试点与核验动作 |
| 审阅已有方案和主张 | 08，按实际缺口返回专业节点 | 原主张、来源与适用性、修订动作 |

对应目录为 `marketing-brief-diagnosis`（01）、`market-audience-insight`（02）、`brand-strategy-positioning`（03）、`campaign-strategy-design`（04）、`content-channel-strategy`（05）、`commerce-conversion-growth`（06）、`cross-border-localization`（07）和 `marketing-evidence-review`（08）。
