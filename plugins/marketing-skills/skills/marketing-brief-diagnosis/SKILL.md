# 营销问题诊断

1. 记录业务结果、目标人群、期望行为、现有表现、时间与资源。用一句话写待做的决策，并标出业务方已经定下的约束。
2. 从实际业务路径拆问题。销量停滞可先检查触达、有效到店或留资、成交及复购。选择与该业务有关的环节，为每个候选原因写明「出现了什么 → 可能因为什么 → 核对哪个信号」。缺少数据时，将原因写为假设。
3. 优先验证会改变当前决策、且可以低成本确认的问题。明确要补的最少信息和可先行的动作，把后续研究、定位、内容或转化工作指向对应专业 Skill。

交付可直接用于讨论的决策句、问题树、优先验证项、所需输入和下一步。引用事实时使用[证据规则](../_shared/evidence.md)。
