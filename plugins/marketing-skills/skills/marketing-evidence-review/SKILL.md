# 营销证据与方案审查

1. 从 Brief、方案和素材中逐条提取会影响决策或对外表达的主张。标注输入事实、公开事实、推断、试验假设、创意表达或已观察结果。定位到具体文件、段落、页码或可访问网址。
2. 对照原始资料检查证据是否直接支持原句，核对时间、地域、人群、分母、完整性、引用资格和访问范围。尤其检查预测或投标目标被写成成效、自述案例外推、试验阈值被写成效果、平台规则失效和演示被概括为产品保证。
3. 按[画面暗示审查](references/visual-claims.md)核对镜头、相邻剪辑及其与声画文字的组合。先记录观众可能得到的性能结论，再对照证据和使用条件，给出修改建议与复核位置。
4. 将每条主张给出可用、限条件使用、待验证或需删除的决定。对需要修订的内容给一条证据可覆盖的表述，并标注拟发布前要验证的条件。原始来源缺失时留下缺口。
5. 使用[证据规则](../_shared/evidence.md)保留来源定位。虚构示例的业务设定只在示例内成立，审核结果用来演示编辑判断。

交付主张台账、可用文案及发布前的核验动作。有画面或脚本时附镜头决定及可执行替换。仅需要审稿时，反馈集中到原方案和证据缺口。
