# 画面暗示的产品性能审查

审稿时覆盖脚本、分镜、成片、封面和商品页图。先静音看画面，再连同字幕、口播与声效一起看。对镜头本身和相邻剪辑分别判断普通观众可能理解出的产品性能、强度和适用条件。

1. 按时间码或镜头编号记录线索。重点检查前后对比、分屏、相邻镜头、快放或跳剪、刻意展示干燥物体、量表图形和承压等使用情境。
2. 把暗示写成一句可核验的主张。例如「湿伞套好后紧贴包内物品，切到物品保持干燥」，可能传达「通勤挤压下也防漏」。
3. 将主张对照与发售款、使用条件和强度相符的证据。样品只能完成拆装演示时，支持的表述是操作与配置。验证条件缺失时，删除或重剪产生暗示的画面，保留直接受证据支持的镜头。修改后再连看前后镜头与文案，确认剪辑已消除对应暗示。
4. 记录镜头位置、画面线索、观众可能得到的结论、证据与适用条件、决定、替换镜头和复核人。只收到文案或分镜时，交付脚本或拟议镜头的意见，并标明成片逐帧复核待进行。
