# 市场与消费者洞察

1. 界定决策、品类、人群、区域和时间。记录现有数据的样本、分母、来源与适用范围。公开材料按题目需要检索，优先使用原始调查、可追溯业务数据和相关机构原文。
2. 将可观察行为和原话整理成「人群张力 → 需求 → 场景 → 机会 → 验证」。每条解释写出证据和至少一个可区分的竞争解释。销量变化、平台热度和消费需求分别核对。
3. 依据证据充分度决定交付层级。事实充足时给出机会及适用条件。证据不足时给出细分假设、访谈或数据采集对象、问题和能支持或推翻判断的信号。规模、份额和因果判断需要匹配口径的证据。

交付研究问题、证据与解释、机会、风险和研究动作。证据表按[证据规则](../_shared/evidence.md)保留出处。
